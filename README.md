# Uber-Ride-Analysis-Dashboard
This project focuses on analyzing Uber ride data using Tableau to identify ride patterns, peak hours, trip distances, and customer behavior. An interactive Tableau dashboard was created to convert raw ride data into meaningful visual insights.
Objectives
Analyze Uber ride demand over time.
Identify peak riding hours and busy days.
Analyze trip distance and ride duration.
Understand pickup and drop-off location patterns.
Identify ride trends based on different categories or purposes.
Create an interactive dashboard for better data-driven analysis.
Tools & Technologies
Tableau – Data visualization and dashboard creation
Excel / CSV – Dataset and data preparation
Calculated Fields – Data analysis
Filters & Parameters – Interactive analysis
Maps & Charts – Geographical and trend analysis
Dashboard Features
Total Rides
Total Trip Distance
Average Trip Distance
Average Ride Duration
Rides by Hour
Rides by Day
Monthly Ride Trends
Pickup & Drop-off Location Analysis
Interactive filters for date, time, category, and location
Key Insights

The dashboard helps identify high-demand periods, frequently used locations, ride patterns, and changes in trip activity over time. These insights can be useful for understanding customer behavior and improving operational planning.
